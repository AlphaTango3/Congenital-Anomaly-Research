# Congenital Anomaly Research

## Aim
Investigate patterns and potential risk factors associated with congenital anomalies using a clinical dataset of maternal, antenatal, delivery, and neonatal examination records.

## Reproducing this analysis
1. Clone this repository and open `Congenital Anomaly Research.Rproj` in RStudio.
2. Run `renv::restore()` in the console to install the exact package versions used.
3. Run the scripts in `scripts/` in numeric order (e.g. `01_data_exploration.Rmd` first).
4. Rendered outputs land in `figures/` and `tables/`; the manuscript draws on those.

## Folder structure
- `data_raw/` — the dataset as received, prior to any R-based processing. **Treated as read-only**: scripts only ever read from here, never write to it.
- `data_derived/` — any recoded, merged, or computed data produced by scripts in `scripts/`.
- `scripts/` — all `.R` and `.Rmd` analysis files, run in numeric order.
- `figures/` — plots generated by scripts.
- `tables/` — summary tables generated by scripts.
- `manuscript/` — the written report/paper drawing on the above.

## Data provenance
The file in `data_raw/dataset.csv` is the starting point for all analysis in this repository. It was compiled from clinical records; entries that were originally unusable in their source form (e.g. inconsistent free-text fields, manual transcription errors) were corrected *before* this file was created, outside of this R pipeline.

## Data dictionary

**Sample size:** 500 records, 41 variables.

| Column | Type | Description |
|---|---|---|
| `Id` | Integer | Unique record identifier |
| `maternal_age` | Integer | Maternal age in years |
| `consanguinity` | String (Yes/No) | Whether parents are consanguineous |
| `consanguinity_degree` | String | Degree of consanguinity if applicable (e.g. "3rd"); `NA` if not consanguineous |
| `registered_antenatally` | String (Yes/No) | Whether pregnancy was registered for antenatal care |
| `anc_immunisation` | String (Yes/No) | Whether antenatal immunisation was received |
| `anc_anomaly` | String (Yes/No) | Whether an anomaly was flagged on antenatal scan |
| `anc_anomaly_diagnosis` | String | Antenatal anomaly diagnosis if flagged; `NA` otherwise |
| `maternal_medical_history` | String | Maternal medical history (e.g. "No", "PIH") |
| `iufd_history` | String (Yes/No) | History of intrauterine fetal death in prior pregnancies |
| `obstetric_history_raw` | String | Raw obstetric history code, e.g. `P2L1D1A2` (Para/Living/Deaths/Abortions) |
| `para` | Integer | Parity |
| `living_children` | Integer | Number of living children |
| `child_deaths` | Integer | Number of child deaths |
| `total_abortions` | Integer | Total number of abortions |
| `spontaneous_abortions` | Integer | Number of spontaneous abortions |
| `mtp_abortions` | Integer | Number of medical termination of pregnancy abortions |
| `family_history_congenital_anomaly` | String (Yes/No) | Family history of congenital anomaly |
| `delivery_mode` | String | Mode of delivery (e.g. NVD, LSCS) |
| `sex` | String | Infant sex |
| `gestation` | String | Gestational category (e.g. Term, Preterm) |
| `growth_restriction` | String (Yes/No) | Presence of growth restriction |
| `birth_weight` | Float | Birth weight in kg |
| `APGAR` | String | APGAR scores, comma-separated (e.g. "8,9,9" for 1/5/10 min) |
| `nicu_required` | String (Yes/No) | Whether NICU admission was required |
| `heart_rate_status` | String | Heart rate status (e.g. Normal, Bradycardia) |
| `cyanosis` | String (Yes/No) | Presence of cyanosis |
| `pallor` | String (Yes/No) | Presence of pallor |
| `growth_status` | String | Growth status category (e.g. AGA) |
| `spine_abnormality` | String (Yes/No) | Spine abnormality present |
| `limb_/_musculoskeletal_abnormality` | String (Yes/No) | Limb/musculoskeletal abnormality present |
| `craniofacial_abnormality` | String (Yes/No) | Craniofacial abnormality present |
| `urinary_abnormality` | String (Yes/No) | Urinary abnormality present |
| `rs_abnormality` | String (Yes/No) | Respiratory system abnormality present |
| `cvs_abnormality` | String (Yes/No) | Cardiovascular system abnormality present |
| `cns_abnormality` | String (Yes/No) | Central nervous system abnormality present |
| `pa_abnormality` | String (Yes/No) | Per-abdomen abnormality present |
| `genital_abnormality` | String (Yes/No) | Genital abnormality present |
| `diagnosis` | String | Final diagnosis, if any (e.g. "HIE") |
| `remarks` | String | Free-text clinical remarks |
| `congenital_anomaly` | String (Yes/No) | **Primary outcome**: presence of a congenital anomaly |
